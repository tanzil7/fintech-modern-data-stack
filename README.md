# Fintech Modern Data Stack Platform

An end to end analytics engineering project that transforms raw fintech operational data into tested, documented, and analytics ready datasets.

## Business Scenario

A fictional financial technology company provides digital accounts and debit cards. The platform processes customer, account, card, merchant, transaction, balance, and dispute data for Finance, Product, Risk, and Operations reporting.

## Planned Architecture

1. Python generates and ingests synthetic financial data.
2. Snowflake stores raw and transformed data.
3. dbt cleans, tests, documents, and models the data.
4. Apache Airflow orchestrates the pipeline.
5. GitHub Actions validates code changes.
6. Power BI presents business metrics.

## Technology Stack

Python, SQL, Snowflake, dbt, Apache Airflow, Docker, GitHub Actions, and Power BI.
